# CHEATAI — ЧИТАЙ БУДУЩЕЕ

AI-медиа в стиле комикс/поп-арт. Медиапроект BONGO GROUP.

**Стек:** Next.js 16 (App Router, SSR/SSG + ISR) · TypeScript · Tailwind CSS 4 · PostgreSQL · Payload CMS 3 (встроен в то же приложение, админка на `/admin`).

---

## Быстрый старт (локально)

Нужно: Node.js 22+, PostgreSQL 14+.

```bash
npm install
cp .env.example .env          # заполните DATABASE_URL и PAYLOAD_SECRET
npm run dev                   # http://localhost:3000, схема БД создастся сама
npm run seed                  # демо-контент + администратор (пароль выведется в консоль)
```

- Сайт: http://localhost:3000
- CMS: http://localhost:3000/admin (логин из вывода `npm run seed`, по умолчанию `admin@cheatai.ru`)

Свой пароль администратора: `SEED_ADMIN_EMAIL=... SEED_ADMIN_PASSWORD=... npm run seed`.

> ⚠️ `npm run seed` **удаляет** статьи, инструменты, сравнения, промпты, страницы, теги, категории и медиа. Запускайте только на пустой базе.

## Переменные окружения

| Переменная | Что это |
| --- | --- |
| `DATABASE_URL` | Строка подключения PostgreSQL |
| `PAYLOAD_SECRET` | Длинная случайная строка (`openssl rand -hex 32`) |
| `NEXT_PUBLIC_SITE_URL` | Публичный адрес без слеша в конце, напр. `https://cheatai.ru` |
| `DEMO_MODE` | `true` — показывать черновики и закрыть сайт от индексации (staging). В продакшене — `false` |
| `DISABLE_JOBS` | `true` — отключить фоновый запуск отложенных публикаций (для serverless) |

## Демо-режим и публикация

Весь демо-контент создан **черновиками** с флажком «Демо-материал» — как требует ТЗ, до редакционной проверки.

- `DEMO_MODE=true` — черновики видны на сайте с пометкой «черновик», весь сайт `noindex`, `robots.txt` закрыт, sitemap пустой.
- `DEMO_MODE=false` — на сайте только опубликованное.

Порядок запуска: редакция проверяет материал → снимает флажок «Демо» → нажимает **Publish**. Дата публикации ставится автоматически в момент публикации.

## Что есть в CMS

- **Статьи** — разделы (Новости AI / Нейросети / Гайды / AI для бизнеса → URL `/news/`, `/articles/`, `/guides/`, `/business/`), категория, теги, авторы, обложка, визуальный редактор (таблицы, изображения, ссылки), комикс-блоки **ВАЖНО! / ЛАЙФХАК! / ВЫВОД / WOW-ФАКТ**, блоки кода и промптов с кнопкой «Копировать», интерактивные сравнения-вкладки, FAQ (→ FAQPage), источники, связанные статьи.
- **Черновики, автосохранение, предпросмотр, отложенная публикация** (кнопка Schedule Publish), история версий.
- **SEO у каждого материала:** meta title/description/image, slug, canonical, noindex.
- **Каталог AI-инструментов** (`/tools/`), **Битва нейросетей** (`/compare/`), **Библиотека промптов** (`/prompts/`), **Страницы** (о проекте, контакты, реклама и т.д.).
- **Главная страница** (глобальные настройки): статья дня, «Горячее», подборка гайдов, битвы. Если не заполнено — подбирается автоматически по флажкам.
- **Реклама** — рекламные места с маркировкой (пометка «Реклама», рекламодатель, erid). Внешняя реклама без erid и рекламодателя не показывается.
- **Подписчики и обращения** — из форм на сайте (антиспам: honeypot, таймер, лимит запросов).
- **Редиректы 301** — при смене slug добавьте старый путь, сайт перенаправит.
- **Роли:** Администратор · Редактор (публикует) · Автор (только черновики).

Оглавление статьи строится автоматически из заголовков H2/H3.

## SEO

SSR/ISR, человекопонятные URL, один H1, canonical, Open Graph/Twitter, `sitemap.xml`, `robots.txt`, `rss.xml`, HTML-карта сайта, хлебные крошки, Schema.org (Organization, WebSite + SearchAction, BlogPosting/NewsArticle, BreadcrumbList, FAQPage, SoftwareApplication, Person), пагинация с self-canonical, фильтры каталога и страницы поиска — `noindex, follow`, тонкие страницы тегов — `noindex`, настоящая 404.

В «Настройках сайта» укажите ID Яндекс Метрики и коды подтверждения Яндекс Вебмастера / Google Search Console.

## Поиск

Поиск по статьям, инструментам, промптам и сравнениям — по заголовкам и тексту, с подсказками при вводе (Ctrl+K или `/`) и исправлением опечаток через PostgreSQL `pg_trgm`. Результаты поиска не индексируются.

## Деплой (production)

```bash
npm ci
npm run payload migrate    # применяет миграции из src/migrations
npm run build
npm start                  # порт 3000
```

Подойдёт любой хостинг с Node.js и PostgreSQL (VPS, Railway, Timeweb Cloud и т.п.).

**Важно для продакшена:**
1. `DEMO_MODE=false`, `NEXT_PUBLIC_SITE_URL=https://cheatai.ru`, новый `PAYLOAD_SECRET`.
2. Медиа сейчас хранятся в папке `media/` на диске сервера — нужен постоянный диск (volume) или подключите S3-хранилище (`@payloadcms/storage-s3`).
3. Отложенная публикация работает на постоянно запущенном сервере. На serverless поставьте `DISABLE_JOBS=true` и вызывайте `/api/payload-jobs/run` по крону.
4. Для отправки писем рассылки подключите email-адаптер Payload (SMTP) или выгружайте подписчиков в сервис рассылок.
5. Тексты «Политика конфиденциальности» и «Пользовательское соглашение» — шаблоны, их должен проверить юрист и дополнить реквизитами оператора.

## Что настроить вне кода

- Зарегистрировать домен `cheatai.ru` и направить на сервер.
- Яндекс Вебмастер и Google Search Console → добавить сайт, отправить `https://cheatai.ru/sitemap.xml`.
- Яндекс Метрика → ID в «Настройках сайта».
- Для внешней рекламы — договор с ОРД и получение erid.

## Структура

```
src/
  app/(frontend)/   — сайт: главная, разделы, статьи, каталог, сравнения, промпты, поиск, sitemap, rss
  app/(payload)/    — админка и API Payload
  collections/      — модели CMS
  blocks/editor.ts  — визуальный редактор и комикс-блоки
  components/       — UI: логотип, маскот, карточки, формы, шапка, подвал
  lib/              — доступ к данным, поиск, SEO
  migrations/       — миграции БД
  seed/             — демо-контент и генератор комикс-обложек
```

## Примечание о Prisma

В ТЗ упомянута Prisma ORM. Payload CMS работает с PostgreSQL через собственный слой (Drizzle) и сам ведёт схему и миграции. Вторая ORM над той же базой дублировала бы миграции и типы, поэтому все данные (контент, подписчики, обращения, реклама) живут в одной системе с единой админкой.

## Railway

Проект уже настроен под Railway (`railway.json`, `.nvmrc`):

- сервис **Postgres** + сервис **web** (этот репозиторий), том `/app/media` для картинок;
- переменные `web`: `DATABASE_URL=${{Postgres.DATABASE_URL}}`, `DATABASE_PUBLIC_URL=${{Postgres.DATABASE_PUBLIC_URL}}` (нужен только во время сборки), `PAYLOAD_SECRET`, `NEXT_PUBLIC_SITE_URL`, `DEMO_MODE`, `PAYLOAD_DB_PUSH=false`, `SEED_IF_EMPTY=true`;
- миграции применяются автоматически при сборке, демо-контент — при первом старте на пустой базе. Пароль администратора печатается в логах деплоя (строка `[seed] создан администратор`).
